# Legacy Skill Wiki and Prime v1 documentation

These documents describe the pre-Kernary product, the v1 compatibility model,
and historical governance or roadmap material. They may contain fixed Atom kind
lists, relation verbs, `domain.yaml`, old package names, and superseded command
examples.

Use them only when maintaining the `.prime` v1 syntax, `prime/*` protocol IDs,
the legacy CLI alias, or an old Corpus. Current product documentation starts at
[`../README.md`](../README.md).

The files are preserved so migration work has evidence. Do not copy their
architecture claims into a current guide without checking the v0.2 code and
external package boundary.
