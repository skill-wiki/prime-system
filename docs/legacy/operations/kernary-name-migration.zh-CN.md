当前产品是 **Kernary —— 模型驱动的本体引擎**。请改读
[开始指南](../../start/index.zh-CN.md)、[Package 模型](../../concepts/package-model.zh-CN.md)
和[Release 运维](../../operations/releases-and-migrations.zh-CN.md)。

网站叙事统一到 Kernary。旧标识只可能出现在历史提交和旧测试夹具里；新增包和
文档应统一使用当前词汇。
