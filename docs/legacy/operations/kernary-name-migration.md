# Historical: Kernary name migration

This page records the repository and product-name migration from the former
Prime / Skill Wiki vocabulary. It is retained for archaeology only. It is not a
current user guide or a runtime compatibility promise.

The current product is **Kernary — a model-driven ontology engine**. Read the
current [start guide](../../start/index.md), [package model](../../concepts/package-model.md),
and [release operations](../../operations/releases-and-migrations.md) instead.

The migration changed the public repository names, separated the reference
Frontend Design Domain Package from Core, and moved the website narrative to
Kernary. Old identifiers may still appear in historical commits and serialized
fixtures; new packages and documentation should use the current vocabulary.
