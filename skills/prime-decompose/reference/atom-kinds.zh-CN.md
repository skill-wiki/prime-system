# 28 种原子类型

原文来自 PRIME-PROTOCOL-v1.md §1.2，逐字复制。

**数据层** — 什么是真的 / 事物是什么：
- `fact` — 有置信度和来源的实证性断言
- `term` — 概念定义
- `value` — 具名的值（数字、颜色、维度）
- `category` — 分类法中的类别
- `example` — 正面示例
- `counter-example` — 反例，展示不应做什么
- `source` — 可引用的参考文献（论文、规范、指南）
- `metric` — 可测量的阈值或基准

**行为层** — 能做什么：
- `step` — 序列中的离散操作
- `check` — 对产物的通过/失败断言
- `transform` — 从一种形式到另一种形式的映射
- `tool` — 具名的软件工具或 API
- `method` — 有输入/输出的多步骤过程

**组合层** — 如何组装事物：
- `rule` — 规范性约束（"始终 X"、"绝不 Y"）
- `taxonomy` — 分类层次结构
- `pattern` — 有变体的可复用设计模式
- `anti-pattern` — 应主动避免的模式
- `type` — 结构类型定义

**风格 / 参数层** — 美学与声音参数：
- `persona` — 有字体/颜色/密度/动效合约的连贯设计流派
- `voice` — 写作风格或语调约定
- `constraint` — 不可覆盖的硬性限制
- `template` — 可复用的代码/标记模板
- `provocation` — 对正统观念的刻意挑衅

**元层** — 知识组织：
- `collection` — 可发布的原子集合（映射为一个 Skill）
- `scope` — 定义具名的命名空间边界
- `tradeoff` — 两个有效立场之间的显性张力
- `principle` — 高层级启发式规则（不可直接操作）
- `feedback` — 对先前决策的回顾性观察
