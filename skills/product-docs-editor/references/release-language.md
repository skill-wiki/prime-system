# Release and brand language

Kernary is the product brand. Its category is Model-driven Ontology Engine.

Use `Kernary` for the product, engine, SDK family, documentation, and current
CLI. Use `Prime` only for an explicit compatibility surface: the `.prime` source
extension, `prime/*` protocol identifiers, the legacy `prime` CLI alias, or a
historical v1 document. Use `AOE` only when naming the former brand,
current unrenamed GitHub/npm location, or a redirect source.

Do not claim that the GitHub organization, npm scope, domain, registry, or old
URLs have migrated until the corresponding external operation has completed and
been verified.

Preferred description:

> Kernary compiles domain models and corpora into versioned runtimes agents can
> query, plan against, and act through.

Preferred category line:

> A model-driven ontology engine for agents and domain-aware software.

Avoid using “knowledge kernel” as the only explanation. It is a brand story, not
the product contract.
