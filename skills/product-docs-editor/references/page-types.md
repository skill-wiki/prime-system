# Page types

Choose one primary type for a page.

## Tutorial

Assume a first successful run. State prerequisites, use a maintained example,
show the expected result, and end with one next step. Do not enumerate the whole
product.

## Guide

Help a reader complete one real task. Explain choices only where they affect the
task. Include rollback or recovery when the task mutates state.

## Concept

Explain a durable mental model, its trade-offs, and its boundaries. Use examples
from at least two domains when the claim is about Core.

## Reference

Lead with syntax, signatures, fields, defaults, errors, and compatibility. Source
generated material from code or schema. Narrative belongs in linked concepts.

## Operations

Name the state transition, preconditions, evidence, failure modes, and recovery.
Distinguish publication, activation, migration, and rollback.

## Migration

State old and new identifiers, the compatibility window, what remains stable,
what changes identity, and the exact verification command. Never imply that a
remote rename, package publication, or redirect exists before it does.
