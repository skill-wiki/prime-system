# Source notes

Prepare four separate blocks before drafting:

1. **Claim** — the one judgment the piece will make.
2. **Evidence** — repository facts, commands, dates, measurements, and links.
3. **Author material** — actual decisions, quotes, and voice samples supplied by
   the author.
4. **Unknowns** — facts that remain unverified or decisions not yet made.

Do not promote an unknown into a confident transition. Do not use test counts as
the story when the meaningful change is a new contract or boundary. A release
note should distinguish code that exists locally from packages, domains, and
redirects that have actually been published.

For bilingual writing, preserve the claim and evidence but rewrite the sentence
flow for each language. Do not mirror English clause order into Chinese.
